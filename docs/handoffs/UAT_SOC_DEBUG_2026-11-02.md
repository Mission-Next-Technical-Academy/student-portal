## UAT method and verification limits

The owner exercised the staging portal in Chrome using real clicks and typing through Learn It, lesson tasks, Guided Lab, Prove It, and instructor grading. Each module's inputs were saved; browser data except the auth token was cleared; the page was hard refreshed; persistence was checked; the lab was submitted; and the grader approved or returned it. Double-submit behavior was checked. A local Playwright/CDP harness and screenshots supported the run. Account names and tokens are intentionally omitted.

The original run log and test harness are local to the owner and are not part of this public repository. Browser session storage is cleared by a full origin data wipe, which signs out open tabs; preserve the auth token and restore it when reproducing that persistence check. Idle sessions may also be signed out by the server.

For code verification, each fix below was committed independently unless it addresses a shared component affecting several findings. Focused regression tests are named below. The final `bin/ci-check.sh` and hosted PR checks must be rerun after this handoff and final code commit. Automated tests do not replace a fresh student/grader live check. U2 still needs a live recheck with a fresh student; PR #79's B9 fix and any other item marked for live follow-up must be checked on the deployed environment.
