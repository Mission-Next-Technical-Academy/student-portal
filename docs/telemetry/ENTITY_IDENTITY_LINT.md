# Entity identity lint

Generated by `node scripts/soc-entity-identity-lint.js` (report-only; `--strict` exits 1 on violations).
Contract: `docs/telemetry/SOC_TELEMETRY_SCHEMA.md` ("Entity identity contract"). Do not edit by hand; regenerate.

Scope: every console table for M01-M12 (guided + assessment) except derived `UnifiedEvents` and `IpIntel`. Counts are violations (one row can hit several rules); "rows" are distinct offending rows.

## Rules

| Id | Rule | Meaning |
|---|---|---|
| H1 | host-case | Host/DeviceId is not lower-case |
| H2 | host-free-text | Host/DeviceId holds free text (not a hostname token) |
| H3 | host-deviceid-mismatch | Host and DeviceId both set but differ (ignoring case) |
| H4 | host-empty | Host key present but empty on a host-bearing table |
| A1 | account-qualified | Account carries a domain prefix (CORP\user) or UPN (user@domain) |
| A2 | account-case | Account is not lower-case (e.g. SYSTEM) |
| A3 | account-free-text | Account holds free text or a placeholder (spaces, "unassigned", ...) |
| A4 | account-empty | Account empty on a table where it is required |
| K1 | noncanonical-key | Entity stored under a non-canonical key (Source, Device, Hostname) |
| S1 | eventsource-not-table | EventSource differs from the table name |

### Phase 2 rules of engagement

1. Change the fixture value and every string that references it (truth ids, rubric, scorer, UI helper, test) in the same session; never half-migrate a module.
2. Keep the native value: where a native form is meaningful (`CORP\user`, `M05-DEV-005`, `SYSTEM`), move it to an additive field (`AccountDomain`, `AssetId`, `RawEvent`) instead of deleting it.
3. Re-run `node scripts/soc-entity-identity-lint.js`, `node scripts/soc-telemetry-inventory.js` (entity counts must not collapse) and `for f in tests/*.test.js; do node "$f" >/dev/null 2>&1 || echo "FAIL $f"; done`.
4. When all modules are clean, add `--strict` to CI.
