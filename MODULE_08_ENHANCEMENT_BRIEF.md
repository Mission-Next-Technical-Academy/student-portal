# Module 08 enhancement brief

## Sprint 9 scope

Upgrade **Vulnerability Findings & SOC Prioritization** to Module 1 parity
without changing its locked catalogue allocation. The module remains 405
minutes (6 hours 45 minutes): four theory lessons at 30/30/20/25 minutes
(105 total) and two 150-minute labs (300 total).

## Learning work

Each existing lesson uses the shared four-part loop:

1. a Mission Next Labs scenario;
2. concise theory tied to the decision boundary;
3. three-question knowledge check with per-answer feedback; and
4. a short applied analyst task saved locally.

The recurring case is a fictional, internet-facing edge-appliance family in a
72-hour mass-exploitation window. Learners compare CVSS, EPSS-style likelihood,
known-exploited context, current reachability, service impact, and controls.
No real IOC, victim, operator, or live system is used.

## Lab contract

Lab 1 remains the six-finding contextual prioritization workbench. Lab 2 is a
fresh, independent edge-appliance queue with four distinct dispositions and a
time-bound owned handoff. Both remain 150 minutes; the second lab is not a new
allocation.

## Guardrails

The Security+ crosswalk is displayed only as a supplementary developer draft;
it is not approval, affiliation, endorsement, or a pass guarantee. Sources are
reviewed as optional references (FIRST CVSS, CISA KEV/SSVC, NIST SP 800-40/RMF,
MITRE CWE). The architecture and catalogue minute ledger remain authoritative.
