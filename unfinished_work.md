# Unfinished Work

## Enrollment-aware student portal — follow-up

The student portal now presents only programs the signed-in student is
actively enrolled in. Direct program routes remain entitlement-gated as a
separate security control.

M360 101 is intentionally separate from the technical program cards. It is
injected as the Career 360 companion for eligible active technical-track
students, including SOC Analyst students, and must remain visible alongside
their enrolled technical program.

If enrollment later supports multiple technical tracks or a different Career
360 eligibility policy, update the source-of-truth enrollment rules and the
M360 eligibility list together; do not reintroduce a public locked-program
catalogue for students.
